سایت عاشقانه برای زندگیم ❤️

محتویات:
- index.html: صفحه اول و دوم
- assets/love-letter.png: عکس/کارت تبریک ارسالی
- assets/love-song.mp3: آهنگ ارسالی

برای انتشار رایگان:
1) وارد GitHub شوید و یک repository جدید بسازید (مثلاً love-surprise).
2) فایل index.html و پوشه assets را در repository بارگذاری کنید.
3) در Settings > Pages، گزینه Deploy from a branch را انتخاب کنید؛ branch را main و folder را /(root) بگذارید و Save بزنید.
4) پس از انتشار، لینک سایت شبیه https://USERNAME.github.io/love-surprise/ خواهد بود.
5) بعد از اینکه لینک واقعی ساخته شد، QR Code را به همان لینک وصل کنید. لینک نمونه بالا را تا قبل از جایگزین کردن USERNAME استفاده نکنید.

نکته: سایت تا وقتی repository و GitHub Pages فعال باشند در دسترس می‌ماند. فایل‌های اصلی را نیز نگه دارید.
